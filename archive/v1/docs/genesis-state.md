# Blank-brain genesis

- Generic (genesis): initial cells, plasticity/structural rules, event/action channels, resource limits, persistence machinery, safety enforcement.
- Acquired (empty at genesis): vocabulary, visual categories, tool skills, policies, episodic/semantic stores, router calibration, compositions.
- Genesis deterministic from (preset, seed); brain identity assigned at create; clone branches lineage without mutating source.
- Current code mapping: `SOMA.create` / `Organism.create_default` = genesis constructor; v15 profile (`inputs 6, hidden 10, max-cells 40, max-synapses 320, max-modules 6`) = one envelope, not universal blank.
